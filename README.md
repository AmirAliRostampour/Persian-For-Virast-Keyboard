# Persian For Virast Keyboard

A hybrid of the Common Persian and Persian Standard keyboard layouts, preserving familiar key positions to minimize the learning curve while improving access to punctuation marks, typographic characters, and tools for smoother Persian text editing.

## Features

- **Familiar key positions:** Retains the familiar arrangement of the Common Persian keyboard to minimize the need to learn a new layout.
- **Improved punctuation access:** Makes punctuation marks and typographic characters easier to access.
- **Persian text editing:** Includes useful characters and typing features for a smoother Persian writing and editing experience.
- **Half-space support:** Supports inserting the Zero Width Non-Joiner (ZWNJ) using `Shift + Space`.

## Installation

1. Download `setup.exe` from this repository.
2. Run the installer.
3. Follow the installation instructions.
4. If the new layout does not appear or the changes are not applied immediately, restart Windows.
5. Select the installed keyboard layout from the Windows language and keyboard settings.

## Usage

Once installed, select **Persian For Virast Keyboard** as your active keyboard layout.

The layout is designed to preserve familiar typing habits while providing more convenient access to the characters commonly needed when writing and editing Persian text.

## Compatibility

- **Platform:** Windows
- **Input method:** Physical keyboard
